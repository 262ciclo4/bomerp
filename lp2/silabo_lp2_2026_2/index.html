    II. Sumilla¶

    La asignatura es de naturaleza teórico-práctica, pertenece al Área de Estudios Específicos y Especialidad y sub área de Ingeniería de Software, tiene el propósito de proporcionar a los estudiantes, Tiene como propósito entrenar al estudiante en el desarrollo de aplicaciones Web con frameworks backend y frontend. Los temas a tratar son: Frameworks backend, Frameworks frontend, interfaz de programación de aplicaciones y seguridad

    III. Competencia del perfil de egreso en relación a la asignatura¶

    General
    Desarrolla y aplica habilidades de investigación científica y formativa, así como la capacidad de innovar de manera ética y basada en principios bíblico-cristianos, para contribuir al avance del conocimiento y la solución de problemas en la sociedad.
    Dimensiones
    N° 1.1INNOVACIÓN Y SOLUCIÓN DE PROBLEMAS
    Específica
    Gestiona y desarrolla software de manera eficiente y efectiva, basándose en estándares internacionales de calidad a fin de lograr el control y aseguramiento de la calidad según el contexto de la organización.
    Dimensiones
    N° 1.1PROGRAMACIÓN

    IV. Resultado de aprendizaje de la asignatura¶

    Resultado de aprendizaje Producto Académico
    Al finalizar el curso, el estudiante desarrolla una aplicación Full-Stack empresarial integrada, articulando backend REST, frontend SPA, seguridad, persistencia, optimización, monitoreo, pruebas, estabilización y sustentación técnica. Nombre: Aplicación Full-Stack empresarial integrada, optimizada, monitoreada, estabilizada y preparada para producción, con evidencias y sustentación técnica.
    Descripción: Backend REST + Frontend SPA + Seguridad + Persistencia + Optimización + Monitoreo + Pruebas + Estabilización.

    V. Unidades de aprendizaje¶

    Unidad 1: Backend REST empresarial¶

    Resultado de aprendizaje Producto
    Desarrolla un backend REST empresarial ejecutable, conectado a la base de datos y organizado por capas, con ORM, recursos, DTO, documentación de API, CRUD, objetos relacionados, operaciones del dominio con cabecera–detalle, consultas, reportes, CORS, logs y pruebas de API. Nombre: Backend REST empresarial con ORM, CRUD, objetos relacionados, operación cabecera–detalle, consultas, reportes, CORS, logs y pruebas.
    Criterios de evaluación del producto Descripción del producto
    1 Crea y configura el proyecto backend con ORM, conexión a la base de datos, recurso REST inicial, DTO y documentación OpenAPI.
    2 Implementa un CRUD REST completo mediante entidades, repositorios, servicios y controladores; aplica transversalmente validaciones, excepciones, logs y pruebas.
    3 Gestiona objetos relacionados mediante ORM, DTO y reglas de asociación.
    4 Implementa una operación cabecera–detalle con registro atómico, cálculos, estados, consistencia, commit y rollback.
    5 Implementa consultas, filtros, ordenamiento, agregaciones, reportes y configuración CORS para el futuro frontend, sin paginación.    		 Backend REST empresarial con ORM, CRUD validado, objetos relacionados, operación cabecera–detalle, consultas, reportes, CORS, logs y pruebas de API.

    Unidad 2: Frontend SPA empresarial seguro¶

    Resultado de aprendizaje Producto
    Construye una SPA empresarial conectada al backend REST, con layout y navegación, CRUD de tablas independientes y dependientes, formularios cabecera-detalle, consultas y reportes; integra seguridad mediante JWT en el backend y gestión de sesión, guards e interceptores en el frontend. Nombre: Frontend SPA empresarial seguro, conectado al backend, con navegación modular, CRUD de tablas independientes y dependientes, formularios transaccionales, consultas, reportes y control de acceso.
    Criterios de evaluación del producto Descripción del producto
    1 Crea la SPA con proyecto frontend, layout, menú bar, sidebar, encabezado, módulos, componentes, rutas, navegación, servicios HTTP y CRUD de una tabla independiente.
    2 Implementa CRUD de tablas dependientes mediante selección de datos relacionados, listas desplegables y validación de dependencias.
    3 Implementa formularios transaccionales con cabecera–detalle, cálculos, validaciones, confirmación, consultas y reportes.
    4 Protege el backend con usuarios, hash de contraseñas, autenticación JWT, roles, permisos y endpoints protegidos.
    5 Implementa login, sesión, almacenamiento y expiración del token, guards, interceptores, menú por permisos, rutas protegidas y manejo de respuestas 401/403.    		 Frontend SPA empresarial seguro, conectado al backend, con navegación modular, CRUD de tablas independientes y dependientes, formularios transaccionales, consultas, reportes y control de acceso.

    Unidad 3: Proyecto Integrador Full-Stack¶

    Resultado de aprendizaje Producto
    Optimiza, integra y estabiliza la aplicación Full-Stack empresarial mediante carga diferida, división de código, caché, logging, monitoreo, paginación de listados de alto volumen, auditoría y pruebas de extremo a extremo; finalmente sustenta el Proyecto Integrador. Nombre: Aplicación Full-Stack empresarial integrada, optimizada, monitoreada, estabilizada y preparada para producción, con evidencias y sustentación técnica.
    Criterios de evaluación del producto Descripción del producto
    1 Aplica Lazy Loading, Code Splitting, caché del navegador y Redis cuando corresponda, logging, monitoreo básico y buenas prácticas de despliegue.
    2 Implementa paginación en listados de alto volumen e integra funcionalmente los módulos de la aplicación.
    3 Incorpora auditoría y ejecuta pruebas end-to-end, corrige errores y estabiliza el sistema.
    4 Sustenta exclusivamente el Proyecto Integrador mediante una demostración funcional y defensa técnica.    		 Aplicación Full-Stack empresarial integrada, optimizada, monitoreada, estabilizada y preparada para producción, con evidencias y sustentación técnica.

    VI. Estrategias metodológicas¶

    Estrategias de enseñanza y de aprendizaje que se aplicarán en la asignatura
    1.1 Aprendizaje Basado en Problemas: centra el aprendizaje en la resolución de problemas reales mediante desarrollo progresivo del producto.
    1.2 Estudios de caso: permite analizar situaciones empresariales y traducirlas en funcionalidades backend, frontend y seguridad.
    1.3 Proyectos: organiza el aprendizaje alrededor de una aplicación Full-Stack empresarial integrada.

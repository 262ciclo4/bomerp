    II. Sumilla¶

    Asignatura de Administración de base de datos II pertenece al área de ingeniería de software es de carácter teórico práctico, de tipo obligatorio. Aporta al perfil de egreso en la competencia específica de ingeniería de software, cuyo objetivo es que el estudiante sea capaz de brindar el soporte computacional para la administración de la Base de Datos de las organizaciones. El curso contempla los siguientes aspectos: PL/SQL, gestión de espacios y objetos de base de datos, gestión de usuarios, privilegios, seguridad, respaldos y afinamiento..

    IV. Resultado de Aprendizaje y Producto Académico¶

    Resultado de aprendizajeProducto Académico
    Gestiona los datos de una organización a través de un gestor de base de datos especializado.Nombre: Base datos gestionada aplicada a un Caso de negocio
    Descripción: Para la gestión de datos en una organización mediante un gestor de base de datos específico, se debe realizar: implementación de base de datos, instalación de software de base de datos, creación de objetos (tablas, índices, vistas, secuencias). Programación utilizando el lenguaje de Oracle PL/SQL: creación de procedimientos almacenados, desarrollo de funciones y el uso de triggers. Tareas y funciones de un administrador de bases de datos: gestión de usuarios y seguridad, mantenimiento y monitoreo de base de datos. Copias de seguridad, restauración, recuperación y afinamiento de la base de datos, restaurar la base de datos, optimización de consultas SQL.

    VI. Estrategias de Enseñanza y Aprendizaje¶

    N° Estrategias de enseñanza y de aprendizaje que se aplicarán en la asignatura
    1.1 Aprendizaje Basado en Problemas: centra el aprendizaje en la resolución de problemas reales, una habilidad esencial en casi todas las profesiones. Estimula el pensamiento crítico y la colaboración, elementos clave en el desarrollo de competencias.
    1.2 Simulación: ofrece experiencias prácticas que son esenciales para la aplicación de teorías en situaciones del mundo real.
    1.3 Estudios de caso: desarrolla el pensamiento crítico y la toma de decisiones al analizar situaciones complejas, preparando a los estudiantes para enfrentar problemas similares en sus futuras carreras profesionales.
    1.4 Proyectos: fomentan habilidades de investigacion, gestión del tiempo y trabajo en equipo, todas cruciales en el mundo profesional.

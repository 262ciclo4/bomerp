# Matriz de Competencias — BD2 (Administración de Base de Datos II)

**Propósito:** consolidar en una sola vista `Competencia (SO) → Nivel → Sesión → Criterio de rúbrica → Peso → Umbral de logro → Última medición`, mismo formato construido para [DIST](https://github.com/262dist/pagatu/blob/main/docs/proyecto-sello/matriz-competencias.md) y [Big Data](https://github.com/262bigdata/lambda26/blob/main/docs/proyecto-sello/matriz-competencias.md) — ver esos documentos para la explicación completa de cada sección.

Este documento **no reemplaza** la rúbrica de `bd2-producto.md` — la resume y la conecta con el marco institucional.

**Alcance actual:** BD2 (dentro del Proyecto Integrador del Ciclo 4) solo tiene rúbrica de evaluación construida para **Unidad 1** (`S06`). Ya existen los documentos de producto de Unidad 2 (`proyecto-integrador/u2/bd2-producto.md`, administración empresarial) y Unidad 3 (`proyecto-integrador/u3/bd2-producto.md`, continuidad del negocio) — describen el entregable, pero todavía no tienen su propia rúbrica ni sesión de evaluación. Esta matriz se amplía cuando existan.

## 1. Competencias evaluadas en este curso

| Competencia | Fuente | Naturaleza |
|---|---|---|
| **CE023 — Programación**, Nivel 1 | Malla curricular 2024, línea Ingeniería de Software | Técnica. Evidencia: `BD2` (junto con `FP`, `POO`, `LP1`, cada uno en su propia plataforma). Evidencia completa en Unidad 1. |
| **Competencia General** | Sílabo BD2, sección III / VIII — **inconsistente entre secciones, ver nota abajo** | Transversal, no técnica. |

**Nota sobre la Competencia General de BD2:** el propio sílabo se contradice — la sección III (Competencias del Perfil de Egreso) la nombra **"PENSAMIENTO SUPERIOR"** (dimensión: firmeza de propósito, ejecución, dominio propio, mantener esfuerzo), mientras que la tabla de evaluación de la sección VIII la nombra **"Servicio y misión"**. Antes de usar esta matriz en un informe formal de acreditación, hay que resolver cuál de las dos es la vigente — posiblemente un error de copiado del sílabo, no una decisión intencional.

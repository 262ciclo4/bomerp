# Matriz de Competencias — LP2 (Lenguaje de Programación II)

**Propósito:** consolidar en una sola vista `Competencia (SO) → Nivel → Sesión → Criterio de rúbrica → Peso → Umbral de logro → Última medición`, mismo formato construido para [DIST](https://github.com/262dist/pagatu/blob/main/docs/proyecto-sello/matriz-competencias.md) y [Big Data](https://github.com/262bigdata/lambda26/blob/main/docs/proyecto-sello/matriz-competencias.md) — ver esos documentos para la explicación completa de cada sección.

Este documento **no reemplaza** la rúbrica de `lp2-demo.md` — la resume y la conecta con el marco institucional.

**Alcance actual:** LP2 (dentro del Proyecto Integrador del Ciclo 4) solo tiene rúbrica de evaluación construida para **Unidad 1** (`S06`). Ya existen los documentos de producto de Unidad 2 (`proyecto-integrador/u2/lp2-demo.md`, SPA segura) y Unidad 3 (`proyecto-integrador/u3/lp2-producto.md`, base full-stack final) — describen el entregable, pero todavía no tienen su propia rúbrica ni sesión de evaluación (equivalente a un "S12"/"S15" de LP2). Esta matriz se amplía cuando existan.

## 3. Umbral de logro

Mismo criterio que DIST y Big Data: **≥70% de estudiantes con nivel B (15/20) o superior** por criterio, umbral inicial uniforme.
